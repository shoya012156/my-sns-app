# 🐦 my-sns-app - Laravel製ツイッター風アプリ

## 📘 概要

my-sns-appは、Laravelを用いて作成した簡易的なツイッター風SNSアプリです。  
ユーザー登録・ログイン機能に加え、投稿の作成・編集など基本的なCRUD機能を実装しています。  
初学者としてLaravelの基礎を実践的に学ぶための学習プロジェクトとして開発しました。

---

## 🔧 技術スタック

| 技術         | バージョン・内容                     |
|--------------|--------------------------------------|
| PHP          | 8.2.4                                  |
| Laravel      | 11                                   |
| データベース | MySQL                                 |
| 認証機能     | Laravel Breeze                       |
| テンプレート | Blade                                |
| CSS          | Tailwind CSS                         |

---

## ✨ 機能一覧

- ✅ ユーザー登録・ログイン・ログアウト
- ✅ ユーザー情報の編集(氏名、メールアドレス、パスワード)
- ✅ 投稿の作成（ツイート）
- ✅ 投稿に対するリプライ投稿
- ✅ 投稿一覧表示（新しい順）
- ✅ 投稿とユーザーのリレーション（投稿者名の表示）

---

## 🏗️ 学習の目的と背景

このプロジェクトは以下を目的として開発しました

- Laravelの基本的な構造（MVC）を理解し、実装できるようになる
- ルーティング・コントローラ・モデルの連携を体験する
- 認証機能（ログイン周り）をbreezeを用いて実装をする
- Eloquent ORMの基本的な操作に慣れる
- tailwindcssを用いてのデザインに慣れる

| 学び・気づき                             | 解決方法・参考資料                         |

## 🚀 セットアップ手順

```bash
# クローン
git clone https://github.com/shoya012156/my-sns-app.git
cd mytweet

# パッケージインストール
composer install
npm install && npm run dev

# .env ファイルの作成と設定
cp .env.example .env
php artisan key:generate

# マイグレーション
php artisan migrate

# サーバ起動
php artisan serve
